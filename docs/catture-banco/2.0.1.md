## Riprodurre il confronto

Dalla radice, con Slint Viewer 1.18.1:

```sh
python scripts/qa/capture_banco.py --viewer /percorso/slint-viewer --check
python scripts/qa/capture_banco.py --viewer /percorso/slint-viewer --size 1400x900 --out docs/catture-banco
```

Le quattro immagini sono rendering software delle scene Slint con dati di prova e catalogo italiano. Non provano l’avvio dell’eseguibile Windows, il comportamento delle finestre native o la produzione di un file video.
